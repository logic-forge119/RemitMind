# Submission Checklist

## README must contain (rulebook section 6)
- [ ] Project overview, features, AI usage
- [ ] Technology stack
- [ ] Requirements
- [ ] Step-by-step install and setup
- [ ] Environment variables (placeholders only)
- [ ] Run and build commands
- [ ] Live deployment URL
- [ ] Testing instructions
- [ ] Other configuration

## Deliverables
- [ ] Public GitHub repo with continuous commit history (not one final upload)
- [ ] Video demo: how it works, features, AI components, real-life impact
- [ ] Project report: problem, idea, solution, features, AI approach, impact
- [ ] Live URL tested from another device
- [ ] External APIs/models disclosed in README (rule 4.4)
- [ ] Every member can explain design and AI parts (rules 4.5, 9.4)
